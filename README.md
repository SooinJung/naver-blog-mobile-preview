# 📱 네이버 블로그 모바일 미리보기 크롬 익스텐션

## 💡 아이디어 배경

> "블로그를 쓸 때는 보통 컴퓨터로 쓰는데, 사람들은 네이버 블로그를 주로 핸드폰으로 봐요.  
> 그러다 보니 웹에서 문장을 길게 쓰면, 폰으로 봤을 때 이상하게 잘리거나 내가 생각한 포맷/비주얼이 안 나올 때가 있어요.  
> 블로그를 쓰면서 옆에서 바로 '핸드폰에서는 어떻게 보이는지' 실시간으로 보여주는 도구가 있으면 좋겠다!"

---

## 🤔 기획 검토 내용

### 기존에 있는 아이디어인가?

결론부터 말하면: **유사한 도구는 있지만, 네이버 블로그에 특화된 것은 없다.**

- **Tistory, 워드프레스** 같은 플랫폼은 에디터 자체에 '모바일 미리보기' 탭이 내장되어 있음
- **네이버 블로그**는 스마트에디터 ONE을 사용하지만, 공식적으로 실시간 모바일 미리보기 기능을 제공하지 않음
- 크롬 익스텐션 스토어에도 네이버 블로그 전용 모바일 미리보기는 현재 없음 (2025년 기준)

→ **틈새 아이디어로서 충분히 가치 있음.**

---

### 크롬 익스텐션 포맷이 맞는가?

**맞다.** 이유:

| 이유 | 설명 |
|------|------|
| ✅ 설치가 간단 | 스토어에서 클릭 한 번으로 설치 가능 |
| ✅ 별도 앱/서버 불필요 | 로컬에서 동작, 개인정보 이슈 없음 |
| ✅ 특정 URL에만 동작 | `blog.naver.com` 에서만 실행되도록 제한 가능 |
| ✅ 에디터 DOM에 접근 가능 | content script로 실시간 감지 가능 |
| ⚠️ 네이버 에디터 구조 변경 리스크 | 네이버가 에디터 업데이트 시 셀렉터가 깨질 수 있음 |

## 🛠️ 현재 구현 상태

### 파일 구조

```
naver_blog/
├── manifest.json        # 익스텐션 메타정보 (Manifest V3)
├── content.js           # 핵심 로직 (패널 생성 + 실시간 감지)
├── style.css            # 패널 UI 스타일
│
├── docs/                # 문서
│   ├── mobile_design_spec.md   # 실제 네이버 모바일 디자인 스펙 (phone 분석 결과)
│   └── TODO.md                 # 미해결 이슈 & 개선 사항 트래커 (해결 완료 항목 포함)
│
└── reference/           # 레퍼런스 HTML 원본
    ├── phone            # 실제 네이버 블로그 모바일 페이지 전체 HTML
    └── phone_1          # 이미지 슬라이드 컴포넌트 HTML 스니펫
```

### 동작 방식

1. `blog.naver.com` 에 접속 시 content script 자동 실행
2. URL에 `PostWrite` / `write` 포함 여부 또는 에디터 컴포넌트 존재 여부로 에디터 페이지 판단
3. 우측에 390px(모바일 너비) 패널 생성
4. `MutationObserver`로 에디터 변경 실시간 감지 → 패널에 즉시 반영

### 주요 구현 내역

| 기능 | 설명 |
|------|------|
| 실시간 미리보기 | `MutationObserver`로 에디터 DOM 변경 감지 → 300ms debounce 후 반영 |
| 기기 선택 | iPhone 16 / SE / Galaxy S24 등 10종 선택, localStorage 저장 |
| 패널 토글 | ✕ 버튼으로 닫기, 📱 플로팅 버튼으로 재열기 |
| 폰 UI | 상태바(시계·배터리), 네이버 앱바, 좋아요·댓글·공유 바, 하단 탭바 |
| 이미지 슬라이드 | VIEWER_H 고정 + 이미지 비율 기반 item 너비 계산, px 기반 `translateX` |
| 슬라이드 네비게이션 | 각 이미지를 viewport 가운데에 놓는 idealOffset 기반 이동 + maxOffset clamp |
| 슬라이더 바 | thumb `width=1/n` 고정, `left`만 이동. 이미지 모두 보일 때 숨김 |
| 스티커 | `se-sticker` 감지 → 100px 소형 이미지로 별도 렌더링 |
| 폰트 | `se-ff-*` 10종 클래스 매핑, 손글씨 3종 fallback |
| 카테고리 | 에디터 DOM 다중 셀렉터 탐색 → 연도 fallback |
| 닉네임 | DOM 탐색 + API fetch 시도 |

## 📦 설치 방법 (개발 버전)

1. 크롬 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** 활성화
3. **압축 해제된 확장 프로그램 로드** 클릭
4. 이 폴더(`naver_blog/`) 선택
5. `blog.naver.com` 에서 글쓰기 진입 후 확인
