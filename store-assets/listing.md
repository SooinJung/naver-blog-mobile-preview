## 개인정보 보호 관행 탭 (심사 양식)
- **단일 목적:** 네이버 블로그 글쓰기 화면 옆에, 작성 중인 글이 모바일에서 어떻게 보이는지 실시간 미리보기 창을 띄워 줍니다. 다른 기능은 없습니다.
- **호스트 권한 사용 이유:** 이 확장 프로그램은 네이버 블로그 글쓰기 화면(blog.naver.com)에서만 동작합니다. 글쓰기 화면에서 작성 중인 본문을 읽어 옆에 모바일 미리보기를 그리기 위해 blog.naver.com 에 콘텐츠 스크립트를 삽입합니다. 다른 사이트에서는 실행되지 않습니다.
- **원격 코드 사용:** 아니요 (rules.json 은 실행 코드가 아닌 데이터만 받음)
- **데이터 사용 (수집 항목 체크박스):** 아무것도 체크하지 않음. 작성 중인 글은 브라우저 안에서 미리보기를 그리는 데에만 쓰고 개발자나 외부 서버로 전송하지 않음 (구글 기준 "수집"은 기기 밖으로 보내는 것)
- 아래 세 항목 모두 체크: 판매 안 함 / 목적 외 사용 안 함 / 신용도 판단에 사용 안 함
- **설정 페이지:** 게시자 연락처 이메일 입력 → 받은 메일의 인증 링크 클릭
